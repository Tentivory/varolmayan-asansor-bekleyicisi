# Varolmayan Asansör Bekleyicisi

## Resmi Bildiri

Bu yazılım, **hiç inşa edilmemiş bir asansörü** uluslararası standartlara uygun şekilde bekler.

Asansör yoktur.  
Kat yoktur.  
Buton vardır. Butona basılır. Hiçbir şey olmaz.  
Bu, özelliktir.

## Neden?

Çünkü modern hayatın yüzde doksan dördü, henüz gelmemiş bir şeyi beklemektir.  
Bu proje o yüzde doksan dördü bilimsel hale getirir.

## Kuruluş

```bash
python3 bekleyici.py
```

Python 3 yeter. Başka bir şey istemez. Asansör de istemez.

## Kullanım

1. Programı çalıştır.
2. Kat numarası gir. (Örnek: 13, -7, 3.14, "anneannemin evi")
3. Bekle.
4. Daha çok bekle.
5. Asansör gelmez.
6. Bu başarıdır.

## Teknik Özellikler

- Gerçek zamanlı varoluşsal gürültü
- Sahte kat sistemi
- Resmi bekleme tutanağı
- Asla açılmayan kapı simülatörü
- Yüzde 0 asansör teslimatı (SLA karşılanmaktadır)
